# IDEA_ARCHIVE — BPM:160

Ten plik przechowuje elementy jawnie wyłączone z bieżącej bramki Spike 001.

Lokalne statusy pracy BPM:160 to:

```text
DOING NOW / NEXT / BACKLOG / PARKED / DONE
```

Globalny Navigation Protocol Creative OS nie zastępuje tej osi.

## DOING NOW

### SPIKE 001 — lodowcowy kanion

Zakres:

```text
World → Signal → Peak Event → Aftermath
→ montaż próbny z audio
→ Evidence Package
```

Pytanie bramkowe:

> Czy BPM160 da się zrealizować przy akceptowalnej jakości, czasie i koszcie?

## PARKED

### Market Scan v0

Powód: nie odpowiada na bieżącą bramkę wykonalności produkcyjnej.

Warunek powrotu: Spike 001 zakończony, Evidence Package kompletny i jawna decyzja użytkownika o badaniu rynku.

### Testy widzów

Powód: nie należy testować reakcji widza przed potwierdzeniem, że podstawowy format można wykonać w akceptowalnej jakości, czasie i koszcie.

Warunek powrotu: pozytywny albo warunkowo pozytywny wynik Spike 001 oraz zdefiniowany minimalny materiał testowy.

### Pomiar fizjologiczny

Powód: Brand Promise nie jest dosłownym celem medycznym 160 BPM. Pomiar nie jest wymagany do odpowiedzi na bieżącą bramkę.

Warunek powrotu: jawna hipoteza, której nie da się sprawdzić prostszą miarą reakcji.

### Rozszerzenie Canon

Powód: Canon v1.2 ma wystarczyć do Spike 001. Rozbudowa przed wynikiem zwiększa koszt bez dowodu potrzeby.

Warunek powrotu: udokumentowana porażka Spike wynikająca z konkretnego braku w Canon.

### Dodatkowe światy

Powód: bieżący test dotyczy lodowcowego kanionu. Kolejne światy nie poprawiają odpowiedzi na pierwszą bramkę.

Warunek powrotu: zamknięty Spike 001 i decyzja, że potrzebny jest test przenośności formatu.

## Niepotwierdzony historyczny element

### Navigation Protocol BPM:160

Status: `UNRESOLVED / SOURCE REQUIRED`.

Nie ma źródła potwierdzającego, że `CORE / DETOUR / PARKING / DRIFT` było lokalnym protokołem BPM. Do czasu odnalezienia dokumentu traktować je wyłącznie jako protokół globalnego Creative OS.

## Reguła nowych wpisów

Nowy lokalny element BPM:160 powinien otrzymać:

- klasyfikację materiału: `CORE / SUPPORT / EDITORIAL / REJECT`, gdy dotyczy materiału;
- status pracy: `DOING NOW / NEXT / BACKLOG / PARKED / DONE`;
- status decyzji lub wersji: `active / superseded / unresolved`, gdy dotyczy decyzji;
- powód;
- warunek powrotu dla `PARKED`;
- źródło.

Do zamknięcia Spike 001 żaden nowy pomysł nie może zastąpić jego pytania bramkowego bez jawnej decyzji użytkownika.
