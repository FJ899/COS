# IDEA_ARCHIVE — BPM:160

## Stan

Brak dostępnych lokalnych źródeł pozwalających wiarygodnie odtworzyć wcześniejszy parking pomysłów BPM:160.

Nie należy traktować pustej listy jako dowodu, że projekt nie miał dodatkowych pomysłów. Wpisy zostaną odtworzone dopiero po odnalezieniu wcześniejszego parkingu lub po pojawieniu się nowych, jawnych pomysłów.

## Reguła nowych wpisów

Każdy nowy pomysł dotyczący BPM:160 musi zawierać:

- tag `CORE / DETOUR / PARKING / DRIFT`;
- problem lub wartość;
- powód, dla którego nie jest realizowany teraz;
- warunek powrotu dla `PARKING`;
- alias, gdy pomysł powtarza istniejący kierunek.

Do czasu zakończenia `SOURCE RECOVERY` nowe pomysły nie mogą zastępować odzyskiwania źródeł ani automatycznie aktywować projektu.
