# DECISION_LOG — BPM:160

Ten plik przechowuje wyłącznie decyzje i sprostowania semantyczne potwierdzone przez użytkownika. Pliki pierwotne nadal wymagają importu.

## DEC-BPM-001 — projekt pozostaje w kolejce

Status: `ACTIVE`

BPM:160 zachowuje pozycję `QUEUED #2` w Creative OS. Korekta stanu nie zmienia samodzielnie kolejności portfela ani nie aktywuje projektu jako bieżącego projektu wykonawczego COS.

## DEC-BPM-002 — Brand Promise

Status: `ACTIVE`

BPM:160 oznacza adrenalinę i rytm. Nie jest projektem realizującym dosłowny medyczny cel 160 uderzeń na minutę.

## DEC-BPM-003 — Canon v1.2

Status: `ACTIVE / SOURCE FILE REQUIRED`

Canon v1.2 jest konstytucją projektu. Obejmuje między innymi Brand Promise, brak ludzi w Canon, reguły kamery i audio, World Bank, Peak Event, QA, Minimal Montage, Layer Separation i Definition of Done.

## DEC-BPM-004 — Spike 001 jest bieżącą bramką

Status: `ACTIVE`

Bieżącą jednostką pracy jest Spike 001:

```text
World → Signal → Peak Event → Aftermath
```

Projekt odpowiada na pytanie, czy BPM160 jest wykonalny przy akceptowalnej jakości, czasie i koszcie. Do czasu odpowiedzi nie otwieramy nowych analiz ani rozszerzeń.

## DEC-BPM-005 — elementy poza Spike 001 pozostają na PARKING

Status: `ACTIVE`

Na parkingu pozostają:

- Market Scan v0;
- testy widzów;
- pomiar fizjologiczny;
- rozszerzenie Canon;
- dodatkowe światy.

Powrót wymaga zakończenia Spike 001, kompletnego Evidence Package i jawnej decyzji użytkownika.

## DEC-BPM-006 — trzy systemy klasyfikacji są odrębne

Status: `ACTIVE`

Nie wolno scalać następujących osi:

```text
materiały: CORE / SUPPORT / EDITORIAL / REJECT
praca: DOING NOW / NEXT / BACKLOG / PARKED / DONE
decyzje i wersje: active / superseded / unresolved
```

## DEC-BPM-007 — Navigation Protocol nie jest potwierdzonym mechanizmem BPM

Status: `ACTIVE CORRECTION`

`CORE / DETOUR / PARKING / DRIFT` jest globalnym protokołem Creative OS. Brak źródła potwierdzającego jego historyczne użycie wewnątrz BPM:160. Nie wolno przypisywać go projektowi ani zastępować nim lokalnych klasyfikacji bez odnalezienia źródła.

## DEC-BPM-008 — korekta wcześniejszej rekonstrukcji

Status: `ACTIVE`

Opis „perfekcjonizm świata → test widza” był fragmentem obserwacji lub rekomendacji, nie pełnym stanem BPM:160. Następnym krokiem nie jest test widza, lecz import źródeł, reconciliation i dokończenie Spike 001.
