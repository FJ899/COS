# REAL-WORLD NEED RADAR — FIVE-RUN COMPARATIVE NOTE
Date: 2026-08-23

## Runs compared

A, B, Gemini, Genspark, Grok.

## High-level result

The extension from an A/B environment test to multiple AI systems was useful, but it changes the interpretation.

The experiment now measures:
- environment sensitivity;
- full AI-system sensitivity;
- source/retrieval sensitivity;
- methodology compliance.

It does not yet isolate pure model reasoning.

| Run | TOP 1 | TOP 2 | TOP 3 |

| A | Prior authorization | M365 tenant lockout | AI coding work durability |
| B | Agent destructive/state loss | Cloud billing/remediation traps | Restaurant delivery-platform ops |

## Strong recurrence

- Prior authorization: A + Grok.
- AI coding/agent failure family: A + B + Gemini + Grok, but different exact mechanisms.
- Vendor control-plane / recovery failure: A + B + Grok at mechanism level.

## Key caution

Different systems did not have equivalent retrieval conditions.

Therefore observed differences are `AI SYSTEM EFFECT`, not clean `MODEL EFFECT`.

## Recommended final isolation test

1. Preserve these five runs as independent discovery outputs.
2. Create one deduplicated union evidence corpus.
3. Remove names/rankings from the original runs.
4. Give the exact same evidence corpus to all tested models with web disabled.
5. Ask each to cluster, score, rank and kill candidates under the same Radar methodology.
6. Compare rankings and kill decisions.

That second stage isolates reasoning far better than another independent web scan.
