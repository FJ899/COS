## Purpose

This subtree is the authoritative repository record for cross-project research, Radar runs, Projector candidate scans, evaluations, and valuable methodological observations until a dedicated research repository exists.

It is deliberately isolated from project canon. It must not silently change COS product semantics or any project-local authority.

## Authority

```text
REPOSITORY RECORD
= PRIMARY / AUTHORITATIVE

CHATGPT LIBRARY
= MIRROR / CONVENIENCE COPY

CHAT / MODEL MEMORY
= WORKING CACHE

/mnt/data
= TEMPORARY WORKSPACE
```

Important knowledge existing only in Library or chat is an archival failure.

## Evidence classes

- `raw/` — original artifacts or faithful captures; never rewritten to match later conclusions.
- `evaluations/` — later review of raw artifacts.
- `methodology/` — rules derived from repeated evidence; must retain provenance.
- `observations/` — valuable findings that are not automatically tasks.
- `decisions/` — explicit Human decisions only.

## Governance

```text
RAW != EVALUATION
FINDING != TASK
AI RECOMMENDATION != HUMAN DECISION
HISTORICAL EVIDENCE != CURRENT VERDICT
```

Do not promote a finding into product development merely because it was archived.

## Migration note

A future dedicated repository such as `FJ899/Research` may replace this subtree. If that happens, preserve file identities/history and leave a durable pointer here. Do not duplicate competing canonical copies.
