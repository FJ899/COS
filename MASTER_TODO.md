## NORTH STAR

> Build and use a durable Human–AI collaboration ecosystem in which real Human work remains anchored to Human intent, Intelligence uses only the mechanisms that naturally help, consequential effects stay authorized and verifiable, and project state can be recovered without depending on one chat session — without turning every new finding into new architecture or work.

The success condition is not "all components are always used".

The system should use **only what naturally helps the real Human problem**.

```text
REAL HUMAN PROBLEM
→ USE ONLY WHAT NATURALLY HELPS
→ OBSERVE FRICTION
```

The ownership network is a map of responsibility, **not a mandatory pipeline**.

Hard progress boundary:

```text
ARCHITECTURE != PROGRESS
```

A new architecture, component, interface, folder, schema, README claim or agent name does not count as capability progress unless a new observable behavior is demonstrated under the behavior-first policy.

## NIE GOŃ LISKA — GLOBAL INTAKE RULE

Every unexpected finding, idea, failure or attractive new direction must pass this sequence **before becoming work**.

### 0. Safety / integrity preemption

```text
CZY GROZI TO:
- utratą danych,
- złamaniem authority/security boundary,
- nieodwracalnym efektem,
- utratą integrity/provenance?
```

**YES** → `STOP / BLOCKER`; it may preempt the queue.  
**NO** → continue.

### 1. Current-goal blocker

```text
CZY BLOKUJE AKTUALNY CEL?
```

**YES** → `BLOCKER`; it may enter before the queue.  
**NO** → continue.

### 2. Required bounded detour

```text
CZY JEST NIEZBĘDNE DO NAJBLIŻSZEGO TODO?
```

**YES** → `BOUNDED DETOUR` → perform the minimum → return to the prior task.  
**NO** → continue.

### 3. Valuable but not needed now

```text
CZY JEST WARTOŚCIOWE?
```

**YES** → `PARKING + RETURN CONDITION`.  
**NO** → `DRIFT / IGNORE`.

Hard invariant:

```text
FINDING != TASK
```

A finding does not receive work authority merely because it is real, interesting, severe-looking or produced by a test.
