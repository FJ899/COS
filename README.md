# Creative OS — lean pilot

To repozytorium jest osobistą, przekrojową pamięcią projektów i pomysłów użytkownika.

Aktywnym źródłem stanu jest jeden plik: [`CREATIVE_OS.md`](CREATIVE_OS.md).

## Model działania

- szczegóły projektu pozostają w jego lokalnym systemie;
- tutaj zapisujemy stan wysokiego poziomu, miejsce zatrzymania, brak do ukończenia, następny krok i pomysły przekrojowe;
- każdy nowy pomysł trafia do Idea Inbox bez automatycznego rozwijania;
- reguły wypracowane w eksperymencie Cognitive OS są wchłonięte do Creative OS;
- Cognitive OS nie jest dalej rozwijany jako osobny system;
- Navigation Protocol działa jako tag: `CORE`, `DETOUR`, `PARKING`, `DRIFT`;
- Git przechowuje historię zmian i nadpisywanego handoffu.

## Start nowej sesji AI

1. Przeczytaj cały `CREATIVE_OS.md`.
2. Odczytaj lokalne źródło prawdy tylko dla projektu, nad którym ma być wykonana praca.
3. Wskaż sprzeczności, nie zgaduj ich rozwiązania.
4. Wykonuj autonomicznie pracę operacyjną; pytaj użytkownika tylko o zmianę kierunku, celu, priorytetu albo działanie kosztowne, publiczne, ryzykowne lub trudno odwracalne.

## Archiwum

Poprzedni eksperyment jest zachowany w branchach opisanych w [`ARCHIVE_INDEX.md`](ARCHIVE_INDEX.md). Nie kopiujemy go do aktywnego drzewa pod katalogiem `workshop`.

## Workshop

Katalog `workshop/YYYY-MM/` można utworzyć dopiero dla bieżących szkiców roboczych. Nie jest źródłem prawdy ani trwałym archiwum. Każdy materiał musi zostać ostatecznie oznaczony jako `PROMOTED`, `ARCHIVED` albo `DELETED`.
